# Low Poly Vehicles Pack (Free)
by reodesuxz

26 free low poly vehicles: cars, vans, trucks, buses, two-wheelers and boats, ready for Unity, Unreal, Godot and Blender.

## Contents
- FBX/  - one .fbx per model (Unity, Unreal, Godot, Blender)
- GLB/  - one .glb per model (Godot, three.js, Babylon.js, web)
- OBJ/  - one .obj + .mtl per model
- Vehicles_AllAssets.blend - every model in one Blender file (Blender 4.3+)

## Specs
- Total: 11752 triangles for all 26 models (142-992 tris each)
- Flat-shaded, simple shared materials (no textures needed)
- Real-world scale in metres, pivot at the base centre

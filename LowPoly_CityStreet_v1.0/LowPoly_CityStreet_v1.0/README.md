# Low Poly City Street Pack (Free)
by reodesuxz

26 low poly city street props: lamps, benches, hydrants, signs, cones, taxi and more.

## Contents
- FBX/  - one .fbx per model (Unity, Unreal, Godot, Blender)
- GLB/  - one .glb per model (Godot, three.js, Babylon.js, web)
- OBJ/  - one .obj + .mtl per model
- City_AllAssets.blend - every model in one Blender file (Blender 4.3+)

## Specs
- Total: 2374 triangles for all 26 models (24-228 tris each)
- Flat-shaded, simple shared materials (no textures needed)
- Real-world scale in metres, pivot at the base centre
